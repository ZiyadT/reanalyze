# ReAnalyze glossary

Plain-language definitions of the main ideas in ReAnalyze.

| Term | Meaning |
| --- | --- |
| **Document** | A PDF a user uploads to ReAnalyze. An edited PDF uploaded under a different name is treated as another document, much like a new book added to a shelf. |
| **Reprocessing** | ReAnalyze extracting and chunking the same uploaded PDF again, for example after an internal bug fix. It is different from a user uploading an edited PDF. Reprocessing is outside the MVP scope. |
| **Prompt** | The instruction a user gives ReAnalyze to generate a report. The MVP uses it for that request and does not save it afterward. |
| **Report** | A saved text response generated from a prompt and a workspace's current documents. It has a short title and creation date, like a finished memo in a project folder. The prompt itself is not saved. |
| **Workspace** | A named collection where a user organizes documents and reports, like a project folder. Removing a document link does not delete the document. |
| **Citation** | A plain-text reference in a report, such as a document name and page number. In the MVP, it is not a clickable or automatically verified link to the original passage. |
